# Support

Questions and bug reports go to [GitHub issues](https://github.com/JanniezRubyjane/hermes-control/issues).
Use the issue templates for bugs and feature requests; for a question, use the
feature request form and mark the title "Question". Remove secrets and private
paths from any logs before posting.

Report security vulnerabilities privately by following [SECURITY.md](SECURITY.md).

The supported release is the latest 0.1.x on macOS. Linux is untested.
Support is best-effort, with no response-time promise.
